
# Interactive Webpage Using JavaScript

## Project Description

This project focuses on enhancing a static webpage by implementing
interactive features using JavaScript. It demonstrates DOM manipulation,
event handling, form validation, and dynamic content updates.

## Objective

The objective is to improve user experience by adding dynamic
functionality to a webpage using plain JavaScript.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Interactive Features

1. Explore Button – Displays a welcome message when clicked.
2. Mobile Navigation – Opens and closes the navigation menu.
3. Dark Mode – Allows users to switch between light and dark themes.
4. Form Validation – Checks user inputs before submission.
5. Back To Top – Smoothly scrolls the page to the top.
6. Dynamic Footer – Automatically displays the current year.

## JavaScript Concepts Used

- DOM Manipulation
- Event Listeners
- Click Events
- Submit Events
- Conditional Statements
- Functions
- ClassList
- Query Selectors
- Regular Expressions

## Implementation

JavaScript was connected to the HTML page using an external
script.js file.

Event listeners were added to buttons, navigation links,
and the contact form to respond to user interactions.

DOM manipulation was used to update webpage content dynamically
without reloading the page.

## Challenges Faced

- Understanding DOM manipulation.
- Handling different user interactions.
- Validating form inputs.
- Integrating JavaScript without affecting the existing layout.
- Maintaining responsive navigation.

## Solutions

Event listeners were used to handle user actions.
Conditional statements were implemented for form validation.
CSS classes were dynamically added and removed using JavaScript.
The webpage was tested at different screen sizes.

## Testing

The following functionalities were tested:

- Explore button interaction.
- Mobile navigation menu.
- Dark mode toggle.
- Contact form validation.
- Back to top button.
- Dynamic footer year.
